**Version:** 2.0

# Overview

VIK is the utility token of the Vikasa Network ecosystem.

The token is designed to support ecosystem participation, community rewards, platform activities, ecosystem services, and future utility within the Vikasa Network ecosystem.

The maximum supply is fixed at **24,000,000 VIK**.

The deployed VIK smart contract does not provide a public mint function for creating additional VIK beyond the fixed supply.
